# humanizer

A skill that rewrites AI-sounding text so it reads like the writer, based on Wikipedia's "Signs of AI writing".

**Origin:** [blader/humanizer](https://github.com/blader/humanizer), unchanged. **License:** [MIT](https://github.com/blader/humanizer/blob/main/LICENSE), © 2025 Siqi Chen. Installed 2026-10-01 with `npx skills`, which keeps it in `~/.agents/skills/humanizer/`.

## Updating

Reinstall from upstream:

```bash
npx skills add blader/humanizer -g
```

Then copy `~/.agents/skills/humanizer/` into `skills/humanizer/` here.
