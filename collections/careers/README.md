22 skills for resumes, cover letters, applications, interviews and offers.

**Origin:** [Paramchoudhary/ResumeSkills](https://github.com/Paramchoudhary/ResumeSkills), unchanged. **License:** [MIT](https://github.com/Paramchoudhary/ResumeSkills/blob/main/LICENSE). Copied here on 2026-10-09 from an install dated 2026-08-10.

Upstream's README lists 20 skills; its installer also delivers `application-form-filler` and `cold-email-writer`, which are included here.

The email addresses and phone numbers inside these skills (`john@email.com`, `(555) 123-4567`) are upstream's made-up examples.

## Updating

Reinstall from upstream, then copy the updated folders into `skills/` here:

```bash
npx skills add Paramchoudhary/ResumeSkills -g
```
