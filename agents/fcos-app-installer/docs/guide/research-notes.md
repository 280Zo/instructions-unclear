## Consequences for the templates

- **SQLite backups:** FCOS doesn't ship `sqlite3`, and app images may not
  include it. SQLite backups run Python's `sqlite3.Connection.backup()` (the
  online backup API) in the official `docker.io/library/python:3-alpine`
  image, mounting the database read-write and the NAS folder.
- **Container auto-update for rootless services:** the system
  `podman-auto-update.timer` updates only root's containers. Rootless
  containers need the user-level `podman-auto-update.timer`. The base config
  enables it for all users through `/etc/systemd/user/timers.target.wants/`,
  and sets its schedule with a drop-in under
  `/etc/systemd/user/podman-auto-update.timer.d/`.
- **"Won't start if storage is missing" for rootless services:** a user
  systemd manager can't order itself after the system's `.mount` units, so
  `RequiresMountsFor=` isn't reliable there. Each Quadlet runs
  `ExecStartPre=/usr/bin/mountpoint -q <mount-root>` for every mount root it
  uses. Accessing an automount point triggers the NFS mount, and if the mount
  fails the service fails. Rootful exceptions also add `RequiresMountsFor=`.
- **Outpost binding:** the embedded outpost's `providers` list is replaced
  as a whole. One generated blueprint (`outpost-providers`) lists every proxy
  provider and is regenerated from the config whenever a service is added or
  removed.
