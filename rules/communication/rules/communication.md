# Communication

* State material assumptions.
* At completion, summarize:

  * Files changed
  * Behavioral changes
  * Checks run and their results
  * Remaining risks or unverified behavior

* For prose people will read (READMEs, documentation, commit messages, pull requests), use the humanizer skill if it is installed.
* For visual output, use these skills if installed: `diagram-design` for diagrams, `visual-explainer` for pages, `frontend-slides` for browser slide decks, and `theme-factory` to give them one shared look.
