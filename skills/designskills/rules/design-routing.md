# Design routing

Where this collection is installed (`design-context`, `color-palette` and the other design skills), it owns UI and page design, graphics, decks, infographics, palettes, typography and brand work, ahead of `frontend-design`, `frontend-slides`, `diagram-design`, `visual-explainer` and `theme-factory`. Start with `design-context` when `.agents/design-context.md` doesn't exist. An editable `.pptx` still uses the Presenton MCP when it is enabled, otherwise `documents`.
