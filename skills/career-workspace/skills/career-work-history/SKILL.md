# Career work history

## Overview

Produce the user's full, accurate employment history from their records, in the shape the form asks for. This is the official record, not a resume. All source paths are relative to the user's career workspace.

## Sources

- `profile/work-history.md`: employers, dates, locations, managers. Use the **Official title** column, never the Resume title column. Its Notes section explains conflicts.
- `profile/education.md` and `profile/certifications.md` when the form asks for them.

## Process

1. List every employer in the time span the form asks for (all of them if it says "complete"), most recent first, including jobs outside the user's field and overlapping jobs.
2. Fill exactly the fields the form asks for, in its order and date format. If the user names a form type (application, background check, LinkedIn), match it.
3. Where a record is missing or uncertain, mark it in brackets in place, e.g. `[manager unknown]`. Don't guess.
4. After the history, list the uncertain items briefly (one line each), with the conflicting values from the Notes section, so the user can decide.

## Common mistakes

| Mistake | Instead |
| --- | --- |
| Using resume titles | Official titles only |
| Dropping old or short jobs | Every employer in the requested span |
| Filling a gap with a plausible guess | Bracketed marker plus the note |
