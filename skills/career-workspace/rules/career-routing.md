# Career routing

`career-start-application` starts an application from an existing master; `career-master-resume` builds or refreshes that master. `resume-version-manager` owns resume versions, archives and submission tracking; `career-intake` files source records and interview notes; `career-work-history` supplies official employment fields. If a required career skill is missing, report the blocker rather than silently substituting another workflow.
