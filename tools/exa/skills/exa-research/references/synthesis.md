# Synthesizing Research

Use narrative synthesis when the user asks for the current state, what people say, or an integrated answer rather than an entity list.

## Structure

- Lead with the conclusion.
- Organize by themes, not source-by-source summaries.
- Surface credible disagreement with the evidence and when each position applies.
- State confidence: number of independent sources, recency, and whether sources are practitioners or commentators.

For many perspectives, cluster recurring stances, cite 2-3 representative sources per theme, and flag consequential outliers. Give every factual claim an inline source link; quote exact wording and attribute quotations.

Avoid source-by-source recaps, false consensus, stale evidence presented as current, and long essays when a narrow answer was requested.
